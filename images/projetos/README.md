# Imagens de Projetos

Esta pasta contém as imagens/screenshots dos projetos exibidos na seção de portfólio.

## Como adicionar uma imagem de projeto:

1. **Salve a imagem** nesta pasta (`images/projetos/`)
2. **Nomeie o arquivo** seguindo o padrão: `nome-do-projeto.jpg` ou `nome-do-projeto.png`
   - Exemplo: `plataforma-nsend.jpg`
3. **Formatos suportados**: JPG, PNG, WebP
4. **Tamanho recomendado**: 
   - Largura: 800-1200px
   - Altura: 400-600px
   - Proporção: 16:9 ou 2:1

## Projetos configurados:

- **Plataforma Nsend**: `plataforma-nsend.jpg`
  - Se a imagem não existir, será exibido um placeholder SVG

## Dicas:

- Use imagens de alta qualidade
- Otimize as imagens antes de adicionar (reduza o tamanho do arquivo)
- Mantenha um padrão visual consistente entre as imagens
- Screenshots da interface funcionam muito bem!
